# Power BI Uber Dashboard

## Overview

This project is an interactive Power BI dashboard built to analyze Uber trip data. It provides insights into booking trends, revenue, trip distance, payment methods, and ride performance through interactive visualizations and key performance indicators (KPIs).

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* Power Query
* DAX

## Files

* `Uber.pbix` – Power BI dashboard
* `Uber_Dataset.xlsx` – Dataset used for analysis
* `screenshots/` – Dashboard preview images
